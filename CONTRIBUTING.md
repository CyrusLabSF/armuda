# Contributing to Armuda

Thank you for helping improve Armuda.

1. Create a focused branch from the current main development branch.
2. Keep generated Unity folders and credentials out of commits.
3. Open and save the project with Unity `6000.4.0f1`.
4. Run `Armuda > Build > Validate Packaging` before submitting a change.
5. Describe the user-visible behavior, platforms tested, and any scene or prefab changes in the pull request.

Do not submit API keys, signing certificates, keystores, private data, or proprietary third-party assets without written permission.

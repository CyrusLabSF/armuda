# Armuda Windows Community Preview

Run `Armuda.exe`. The application creates writable profiles, worlds, uploads, settings, and logs under `%LOCALAPPDATA%\Armuda`.

Controls:

- Left click selects.
- Right click opens glyph attachments and object actions.
- Hold the mouse-wheel button and drag to look around.
- The scroll wheel adjusts camera distance.

The package intentionally contains no API key, test profile, saved test world, runtime log, or imported user media. AI image preview mode works locally; configure provider credentials through environment variables only.
